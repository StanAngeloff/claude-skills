# claude-skills

Personal Claude Code plugin marketplace by Stan Angeloff.

This repository hosts **Sparks** — a growing collection of Claude Code skills for development workflows.

## Install

Add the marketplace, then install the plugin:

```
/plugin marketplace add StanAngeloff/claude-skills
/plugin install sparks@claude-skills
```

## Usage

Once installed, skills are available as slash commands:

```
/sparks:journal
```

More skills will be added over time. Run `/plugin install sparks@claude-skills` again after updating to pick up new ones.

## Update

Pull the latest marketplace index:

```
/plugin marketplace update claude-skills
```
